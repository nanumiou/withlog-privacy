withlog 개인정보처리방침

시행일: 2026년 7월 29일

대화 내용은 AI 답변 생성을 위해 AI 사업자에게 전송되지만, withlog 서버에 저장되지 않습니다. 원본 기록은 이용자 기기의 암호화 저장소에만 보관됩니다.

1. 기록의 저장 위치

관계 대상, 대화 원본, 관계 요약, 행동 제안 결과는 이용자 기기의 암호화된 데이터베이스에만 저장됩니다. 암호화 키는 기기의 보안 저장소(Android Keystore, iOS Keychain)에 보관됩니다.

withlog는 기기 간 동기화나 서버 백업을 제공하지 않습니다. 기기를 초기화하거나 앱을 삭제하면 기록은 복구할 수 없습니다.

2. AI 답변 생성을 위한 처리

AI 답변과 관계 요약을 생성하기 위해, 해당 요청에 필요한 대화 내용이 withlog 서버를 경유해 AI 사업자의 API로 전송됩니다. withlog 서버는 이 내용을 처리 중 메모리에서만 사용하며 데이터베이스나 로그에 저장하지 않습니다.

현재 이용하는 AI 사업자는 Google(Gemini), OpenAI 입니다. 사업자나 모델이 추가·변경되면 이 항목을 갱신합니다.

회사가 이용료를 부담하는 요금제에서는 해당 사업자의 유료 서비스를 사용하며, 유료 서비스 입력이 모델 학습에 사용되지 않는 정책을 제공하는 사업자를 이용합니다.

3. 서버에 저장하는 정보

  • 계정 식별자(Firebase UID)
  • 요금제, 상태, 잔여 호출 횟수, 결제 기간 정보
  • 요청 식별자와 요청 시각 (중복 차감 방지와 환불 처리 목적)
  • 오류 코드, 토큰 수, 응답 지연 등 운영 지표

대화 내용, 관계 요약, 이용자의 API Key는 서버 데이터베이스와 로그에 기록하지 않습니다.

4. 계정

로그인 없이 이용할 수 있으며, 이 경우 익명 식별자가 발급됩니다. Google 또는 Apple 계정을 연결하면 결제 상태를 이어갈 수 있습니다. 계정 연결로 대화가 서버에 백업되지는 않습니다.

5. 음성 입력

마이크로 입력한 음성은 기기와 운영체제 설정에 따라 Apple 또는 Google의 음성 인식 서버에서 텍스트로 변환될 수 있으며, 이 처리는 해당 사업자의 정책을 따릅니다. 변환된 텍스트는 입력창에 채워지며 이용자가 전송할 때까지 저장되지 않습니다.

6. 이용자 API Key

이용자가 직접 등록한 AI API Key는 기기의 보안 저장소에만 저장되며, 요청 시에만 서버를 경유해 해당 AI 사업자에게 전달되고 요청이 끝나면 폐기됩니다. 키를 서버에 저장하거나 로그에 남기지 않습니다.

이 방식에서는 해당 키가 속한 계정과 요금 등급의 정책이 적용됩니다. 무료 등급을 사용하는 경우 입력이 해당 사업자의 제품 개선에 사용될 수 있습니다.

7. 진단 정보

앱이 비정상 종료되면 Firebase Crashlytics로 오류 스택과 기기 정보가 전송됩니다. 대화 내용은 포함되지 않습니다.

8. 결제

결제는 Apple App Store 또는 Google Play를 통해 처리되며, 구독 상태 관리는 RevenueCat을 이용합니다. withlog는 카드번호 등 결제수단 정보를 수집하지 않습니다.

9. 이용자의 선택과 권리

  • 기기 데이터 삭제: 설정에서 이 기기의 기록을 삭제할 수 있습니다.
  • 계정 삭제: 설정에서 계정과 위 3항의 서버 정보를 삭제할 수 있습니다.
  • 기록 내보내기: 설정에서 기록을 텍스트로 내보낼 수 있습니다.

계정 삭제는 진행 중인 스토어 구독을 자동으로 해지하지 않습니다. 구독 해지는 각 스토어의 구독 관리에서 진행해야 합니다.

10. 보관 기간

서버의 요청 기록은 중복 차감 방지와 운영 감사를 위해 필요한 기간 동안 보관한 뒤 삭제합니다. 계정 삭제 시 해당 계정의 서버 정보는 삭제됩니다.

11. 아동의 개인정보

withlog는 만 14세 미만 아동을 대상으로 하지 않으며, 해당 연령의 개인정보를 의도적으로 수집하지 않습니다.

12. 안전 고지

withlog는 의료·심리상담 서비스가 아닙니다. 위급한 상황에는 119, 112 또는 자살예방 상담전화 109로 연락하시기 바랍니다.

13. 방침의 변경

이 방침이 변경되면 이 페이지에 시행일과 함께 게시합니다.

14. 계정 삭제 요청

앱의 설정 > 계정 삭제에서 직접 삭제할 수 있습니다. 앱을 사용할 수 없는 경우 아래 주소로 요청하시면 처리합니다.

support@franholdings.cloud

삭제 대상: 계정 식별자, 요금제·잔여 횟수 정보, 요청 기록. 기기에 저장된 대화 기록은 기기에서 삭제해야 합니다.
